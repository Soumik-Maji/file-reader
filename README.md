# file-reader
Read file data & return it in string or array buffer format.

**NOTE:** Project is ready to use, with ongoing maintenance and updates to follow. Minor API changes may occur.

Currently supports reading data from - raw strings, html text area input, html file input element & local files which are hosted along with the project.

Future addition - any local file (via NodeJs), any local file when running using NeutralinoJs

Refer to the [GitHub repo test directory](https://github.com/Soumik-Maji/file-reader/tree/release/tests/test-scripts), for usage examples.
